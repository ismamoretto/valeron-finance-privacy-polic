# Política de Privacidade — Valeron Finance

Página estática para GitHub Pages. Preparada em 05/10/2026; ainda não publicada.

## Antes de publicar
- Responsável e contato confirmados pelo usuário: Ismael Moretto, suportevaleronfinance@outlook.com.
- Definir procedimento real e prazos de exclusão, inclusive backups e dados compartilhados. A seção 7 informa que os prazos serão comunicados no atendimento. Não prometer prazos que o atendimento não consiga cumprir.
- Confirmar público etário, região de hospedagem e eventuais práticas externas ao código. Ajustar a política se necessário.
- A página de contato não implementa exclusão automática. Não foi identificado um fluxo completo de exclusão da conta de acesso dentro do app. Conferir esse requisito da Play Store separadamente.

## Publicação no GitHub Pages
1. Entre no GitHub na conta ismamoretto.
2. Crie um repositório público chamado valeron-finance-privacy-policy, com README inicial.
3. No repositório, use Add file > Upload files.
4. Envie index.html e logo.png (os arquivos dentro desta pasta, não a pasta inteira). Confirme em Commit changes.
5. Abra Settings > Pages.
6. Em Source, escolha Deploy from a branch.
7. Escolha main e /(root). Clique Save.
8. Aguarde o processo em Actions finalizar. Em Settings > Pages, abra Visit site.
9. Endereço esperado: https://ismamoretto.github.io/valeron-finance-privacy-policy/
10. Teste o link sem login e no celular. Confira logo, texto e abertura do e-mail.
11. Use a URL publicada no campo Política de Privacidade da Play Console e, quando necessário, no branding OAuth. O app também precisa disponibilizar acesso à política; isso não foi alterado nesta tarefa.

Não envie o projeto do aplicativo, chaves de assinatura, senhas ou arquivos de ambiente. Esta publicação precisa apenas dos dois arquivos da página.

## Atualizações
Edite index.html, atualize a data e faça novo commit no mesmo repositório. O endereço será mantido.
